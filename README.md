# Mike Ted Portfolio

A single-page personal portfolio website built with HTML, CSS, and vanilla JavaScript to showcase projects and testimonials.

## Live Demo
[View Live Site on GitHub Pages](https://mted39313-cmd.github.io/The-website-assignment/) 

## Features
- **Responsive Layout:** Automatically adapts seamlessly from desktop screens down to mobile devices.
- **Dynamic Content Rendering:** Projects and testimonials are stored in JavaScript objects/arrays and injected into the DOM via loops.
- **Smooth Navigation:** Quick-links in the header navigation bar to smoothly scroll across page sections.
- **Clean Architecture:** Strict separation of concerns across `index.html`, `style.css`, and `script.js`.

## Technologies Used
- HTML5
- CSS3 (Flexbox, CSS Grid, Custom Properties)
- JavaScript (ES6+ loops, DOM manipulation)
- Git & GitHub Pages
